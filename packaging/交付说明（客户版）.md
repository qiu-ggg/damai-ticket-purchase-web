# 使用说明

## 解压就能用

把压缩包解压到任意一个文件夹，双击里面的 `大麦抢票.exe` 就是主界面。
**别把 exe 单独拎出来**，它旁边那一堆文件是一起的。

## 电脑上要有什么

Chrome 浏览器。不需要装 Python。

如果之前装过 Python，不用卸，跟这个没关系。

## 跑不起来？先点最上面那个「环境检测」

主界面最上面、标题右边有一个 **「环境检测」** 按钮，点一下就查这台机器缺什么：
Chrome 装没装、驱动版本对不对、网络能不能连上大麦、程序目录能不能写。
有问题的排在前面，每项都写清楚「怎么办」，右边直接给**下载按钮**（点一下开浏览器）。

检测只看看、不动手，不会自己下载东西或者改配置。结论也能一键复制发给我们。

## 第一次使用

1. 双击 `大麦抢票.exe`，进主界面。
2. 点「＋ 新建」加一个账号，在分页里填演出链接、城市、场次日期、票档、观演人和数量。
3. 点「登录这个账号」，在弹出的浏览器里扫码或短信登录一次。登完把浏览器关掉。
4. 回到主界面点「保存并开始」或者「全部账号一起抢」。

登录状态会保存在这个文件夹里，下次不用再登。想让它自动填表登录，就把手机号和密码
填在「手机号 / 密码」那一栏，程序会把它们存进 `credentials.json`（明文，别外传）。

## 数据存在哪

账号、密码、各账号的浏览器登录状态，都写在**程序所在的那个文件夹**里
（`accounts.json`、`credentials.json`、`profiles/` 这些）。

所以：

- 想换台电脑用，把整个文件夹拷走，数据跟着走
- 如果把它放进 `Program Files` 这类没写入权限的地方，程序会自动改用
  `%APPDATA%\大麦抢票\`，数据就不在程序旁边了
- 备份的时候连这些文件一起备

整个文件夹也别直接发给别人 —— 里面有你自己的账号和密码。

## 确认它是好的

打开程序能进到主界面就是好的。

要更细一点，在文件夹里按住 Shift 右键选「在此处打开命令窗口」，执行：

```
大麦抢票.exe --runner --paths
```

它会打印程序目录、资源目录、数据目录分别在哪（数据目录应该就是程序所在的那个文件夹），
再把随包代码逐个检查一遍。截图发过来我们就能看明白。

## 抢到票时手机响一下（可选）

程序支持短信通知。默认是**关**的，不配它程序照常跑。

要开的话需要自己有一个阿里云账号（短信是按条计费的）：

1. 在阿里云短信控制台申请**签名**和**模板**
2. 建一个只授予「短信发送」权限的 RAM 子账号，拿一对 AccessKey
3. 在文件夹里按住 Shift 右键「在此处打开命令窗口」，依次执行：

```
大麦抢票.exe --runner notify --init                  # 先写出一份默认配置
大麦抢票.exe --runner notify --show                  # 看当前配置（手机号都脱敏）
大麦抢票.exe --runner notify --set-secret 你的Secret  # 存密钥
大麦抢票.exe --runner notify --test                  # 发一条试试
```

中间要打开 `notify.json`，把 `enabled` 改成 `true`，填上手机号、签名、模板号，
还有 `template_params`（把短信模板里的变量名对上程序能给的字段，里面写得很清楚）。

AccessKeySecret 单独存成 `notify_secret.txt`（明文），不会出现在 `notify.json` 里。

发不出去时，`notify --test` 会把原因翻成人话告诉你（比如「模板还没审核通过」），
每次发送成功或失败也都会在 `accounts.log` 里留一行。

不配阿里云也行：把 `provider` 留成 `console`，短信内容就只写进日志。
